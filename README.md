# Randevu v2.0

Android + PHP/MySQL tabanlı online randevu ve işletme yönetim platformu.

## v2.0 Core

- İşletme sahibi kayıt / giriş
- İşletme bazlı izole veri
- Hizmet, personel, izin ve randevu bulut senkronizasyonu
- Çevrimdışı mutation kuyruğu ve 409 sürüm çakışması koruması
- v1.3 cihaz verilerini tek seferlik online hesaba aktarma
- Müşteriler için `/r/{isletme-slug}` online randevu sayfası
- Sunucu taraflı müsaitlik ve çift rezervasyon engeli
- Sunucu sahipli WhatsApp hatırlatma kuyruğu
- Android yerel bildirimleri bağımsız olarak devam eder

Backend kurulum ayrıntıları: `backend/INSTALL.md`.

Android sürümü: `2.0.0` / versionCode `20`.
